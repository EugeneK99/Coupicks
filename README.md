# 쿠팡파트너스 상품 추천 사이트 (스타터)

순수 HTML/CSS/JS로 만든 가장 단순한 상품 큐레이션 사이트입니다.
빌드 도구, 서버, 설치 과정이 전혀 필요 없습니다. 파일만 열면 동작합니다.

## 📁 파일 구조

| 파일 | 역할 | 수정 빈도 |
|------|------|-----------|
| `products.js` | **상품 데이터** — 여기만 고치면 됩니다 | 자주 |
| `index.html` | 사이트 본체 (자동 렌더링) | 거의 안 함 |
| `styles.css` | 디자인/색상 | 가끔 |
| `README.md` | 이 설명서 | — |

## ✅ 상품 추가하는 법 (가장 중요)

`products.js` 파일을 열고 `PRODUCTS` 배열에 아래 블록을 복사해 붙여넣으세요.

```js
{
  title: "상품 이름",
  link: "https://link.coupang.com/a/여기에_내_제휴링크",
  image: "상품 이미지 주소",
  price: "29,900원",
  desc: "한 줄 설명",
  badge: "베스트",     // 없으면 "" 로 두세요
},
```

- `title` 와 `link` 는 **필수**입니다.
- 나머지는 비워도(`""`) 됩니다.
- `link` 에는 **본인 쿠팡파트너스 계정에서 생성한 제휴 링크**를 넣으세요.

## 🔗 제휴 링크 따는 법

1. [쿠팡파트너스](https://partners.coupang.com) 로그인
2. 원하는 상품 검색 → **링크 생성** 클릭
3. 만들어진 `https://link.coupang.com/...` 링크 복사
4. `products.js` 의 `link` 값에 붙여넣기

## ⚠️ 꼭 지켜야 할 것 (약관/법규)

- **대가성 고지 문구는 절대 지우지 마세요.** (`products.js` 의 `SITE_CONFIG.disclosure`)
  공정거래위원회 지침 + 쿠팡파트너스 약관상 **의무**입니다. 위반 시 계정 정지·수수료 몰수 위험.
- 본인 링크로 직접 구매(자가구매) 금지.
- 허위·과장 정보 금지.

## 🚀 배포하는 법 (무료, GitHub Pages)

1. GitHub에 새 저장소(repository) 생성
2. 이 폴더의 파일 전체 업로드
3. 저장소 **Settings → Pages → Source: main branch** 선택 후 저장
4. 잠시 뒤 `https://내아이디.github.io/저장소이름/` 주소로 사이트 공개됨

> 로컬에서 미리 보려면 `index.html` 파일을 브라우저로 그냥 열면 됩니다.
