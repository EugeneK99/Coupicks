# 고양이 용품 후보 목록 (쿠팡파트너스 상품 검색, 쿠팡랭킹순, 2026-09-30 조회)

- 출처: partners.coupang.com 상품 검색 결과 (읽기 전용, 링크는 생성하지 않음).
- 가격은 조회 시점 참고용입니다. **사이트/블로그에 가격을 고정 표기하지 마세요** (변동됨).
- "직접 급여/사용" 표시는 블로그 후기로 실경험이 확인된 것만. 나머지는 "조사 후보"이며 후기처럼 쓰면 안 됩니다.

## 1) 습식 사료·파우치 (검색어: 고양이 습식 파우치, 60건)

| 구분 | 상품 | 형태 | 비고 |
|---|---|---|---|
| ✅ 직접 급여 | 동원 뉴트리플랜 모이스트루 참치 / 참치&닭고기 | 80g 파우치 | 이미 링크 보유(products.js) |
| 후보 | 동원 뉴트리플랜 모이스트루 참치와 연어 | 습식 | 같은 라인 다른 맛, 급여 경험 없음 |
| 후보 | 동원 뉴트리플랜 모이스트루 혼합맛(참치…) | 파우치 | 여러 묶음 상품 존재 |
| 후보 | 쉬바 고양이 주식 파우치 (참치+게살, 닭+참치, 연어+참치) | 70g ×24 | 상위 노출 다수 |
| 후보 | 탐사 고메 주식 파우치 (참치&닭가슴살, 참치+게살) | 85g | 10~20개입 |
| 후보 | 위스카스 어덜트/주니어/시니어 주식 파우치 | 80g ×24 | 연령별 라인업 (비교글 소재) |
| 후보 | 로얄캐닌 어덜트 그레이비 인도어 | 파우치 | 브랜드 인지도 높음 |
| 후보 | 사조벤티 주식캔 | 90g ×24 | 캔 타입 |
| 간식 | 펫리서치 짜먹는 츄, 더캣츠 스프 파우치, 조이펫 타우린 워터 | 간식 | 주식과 분리해서 소개 |

가이드 소재: "습식 파우치 vs 캔", "연령별(주니어/어덜트/시니어) 습식 고르기" — 사실 정보 위주로 작성 가능.

## 2) 두부모래 (검색어: 고양이 두부모래, 60건)

| 상품 | 규격 |
|---|---|
| 탐사 두부모래 (오리지널/베이비파우더/라벤더/녹차 등) | 7L ×3·6개 |
| 탐사 가는 입자 1.5mm | 10L ×3·6팩 |
| 메디펫 응고형 매직 가는입자 | 10L ×5개 |
| 팡팡샌드 가는 입자 1.5mm | 10L ×5개 |
| 구구펫 응고형 극세입자 | 11L ×6개 |
| 삼육오일 365샌드 슬림입자 | 1.5mm |
| 푸르미 몬스터캣리터 | 8L ×5개 |
| 네꼬모리 두부국시 나노입자 | 2.8kg ×6 |

가이드 소재: "두부모래 입자 크기·향 선택법" (입자/무향/응고력 비교표 — 사실 스펙은 각 상품 페이지에서 확인 후 기입).

## 3) 다음 액션
1. 사용자가 후기를 쓸 수 있는(직접 써본) 상품을 표시 → `products.js`에 `review` 작성.
2. 써보지 않은 후보로 가이드를 만든다면 "조사 기반 후보 비교"임을 글에 명시.
3. 링크 생성은 사용자 확인 후 진행 (파트너스에 실제 링크가 생성되는 작업).
