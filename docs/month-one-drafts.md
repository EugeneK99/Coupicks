## 발행 전 확인

링크 글 8개는 제품별 정보와 파트너스 링크를 채우기 전까지 발행 보류. 주제만 결정된 원고이며 실제 제품 추천 완료 상태가 아니다. 제목의 확인 대기 표시는 발행 본문에서 제거한다.

상품마다 정확한 이름·옵션·상품 URL·근거 URL·확인 날짜·가격/수량·파트너스 링크를 기록한다. 게시 직전에 옵션·판매 상태·가격을 다시 확인한다. 확인 실패 시 링크 없는 다른 초안으로 교체하고 자동 발행하지 않는다.

10/19의 ‘따로 필요한 게 있는지’ 등 자료 확인을 예고한 후에는 실제 확인을 수행한다. 경험담·후기·효과를 만들어 넣지 않는다. 가격 인하·최저가·베스트셀러 문구는 별도 근거가 없으면 쓰지 않는다.

주말에는 새 게시물 없이 댓글 답변과 성과 기록. 24시간/72시간 조회·댓글·링크 클릭을 기록하고 2주 후 판단한다. 질문 글과 링크 글은 목적이 달라 단순 조회수로만 승패를 정하지 않는다.

## 연결 방식

첫 달: Threads 기본 예약 기능이 이 계정에 표시되는지 확인 후 주 단위 등록. 기본 예약은 별도 개발용 API가 필수는 아니다.
자동화: Threads OAuth 로그인 → 발행 권한 → 검수된 원고 큐 → 서버 스케줄러가 17시에 공식 API 호출 → 게시 ID와 실패 기록. 토큰 갱신과 중복 발행 방지가 필요하다.
쿠팡: 먼저 파트너스 화면에서 실제 링크를 생성해 원고에 넣는 방식. 자동 링크 생성 단계에서는 파트너스 API의 딥 링크 기능을 검토한다. 판매자용 Open API와 혼동하지 않는다. API 사용 가능 여부는 이 계정에서 확인해야 한다.

비밀번호·API 시크릿·토큰을 원고나 채팅에 저장하지 않는다. Threads 계정 연결과 쿠팡파트너스 링크 생성은 별도 작업이다.
