# 살래말래 차별화

핵심 약속: 구매를 부추기기보다 어떤 조건에서 살지, 언제 안 사도 될지 정리한다.

1. 모든 제휴 글에 ‘살 조건’과 ‘패스 조건’을 구체적으로 함께 적는다. 두 항목을 의무적으로 늘어놓기보다 실제 차이가 있을 때만 비교한다.
2. 동일 목적·비슷한 가격대의 정확한 옵션을 비교한다. 싼 제품과 무관한 고가 제품을 붙여 억지 결론을 내리지 않는다.
3. Coupicks에 자료 출처·확인 날짜·수량 기준을 남긴다. Threads 글은 결론, 사이트는 판단 근거 역할.
4. 기존 용품으로 해결되면 새 물건 링크 없이 설명한다. 일반 글에도 독립적인 정보 가치가 있어야 한다.
5. 체험 없는 상품은 구매/사용 후기로 포장하지 않는다. 캐릭터는 허구의 집사가 아니라 구매 기준을 정리하는 편집자다.
6. ‘살래말래’는 글마다 구호로 반복하지 않는다. 자연스러운 질문, 규격 차이, 구매 전 확인 포인트로 시작한다.

첫 달 검증: 링크 글의 클릭만 보지 않고 저장 가능한 정보에 대한 댓글, 비교 질문, 반복 방문을 본다. 자동 댓글과 가짜 썰은 사용하지 않는다. 경쟁 계정보다 성과가 높다는 주장은 아직 하지 않는다.
